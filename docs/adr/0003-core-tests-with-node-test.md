# 0003 — Core tests with `node:test`

- **Status:** accepted
- **Date:** 2026-09-25

## Context

The core must be tested thoroughly, without adding tools to learn and maintain before they are needed.

## Decision

- Core tests use `node:test` and `node:assert`, built into Node.js: no dependencies.
- Node.js 24 runs `.ts` files directly by stripping the types, so tests start without a build step.
- Besides example-based tests, the core has **invariant tests**: hundreds of cases generated by a pseudo-random generator with a fixed seed, so any failure is reproducible.
- For the apps (web, mobile), Vitest will be considered when component tests and browser simulation are needed.

## Consequences

- `pnpm test` works as soon as Node.js is installed.
- Advanced coverage reports are missing for now: they can be added with `node --test --experimental-test-coverage` or with Vitest.
