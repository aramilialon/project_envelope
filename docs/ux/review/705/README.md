Temporary: the last commit of this pull request removes this folder before the merge (`docs/ux/README.md`, "Screenshots"). Shot with Playwright from the mockups opened as files, the strip's description hidden, after the clicks that lead to each state; the phone states capture the phone frame, 360 px wide inside a 392 px window, and check that it does not scroll sideways. The quick assign and scheduled side sheets have no phone layout (the budget month's phone has no toolbar), so those states are desktop only. The desktop accounts list is the workspace settings list (`settings-first-run.html`), which has no phone view; its phone version is `account-register.html`'s accounts list.
